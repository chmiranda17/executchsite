Como conectar

Da configuração à primeira pergunta.

  1. Gere o token em Minha conta. Seu grupo precisa ter permissão para usar o token pessoal de API.
  2. Cadastre o servidor MCP no cliente. Copie o endereço exibido no perfil e configure a autenticação Bearer.
  3. Teste com uma consulta. Comece pelas entregas pendentes de uma empresa à qual você tem acesso.

Dúvidas

Antes de conectar

O que é MCP?

Model Context Protocol é um padrão para conectar agentes de IA a ferramentas e sistemas como o Executch.

Quem decide o que o agente pode acessar?

Seu escritório define as permissões de leitura e escrita. A credencial usada limita as ferramentas e os dados disponíveis ao agente.

O agente pode alterar informações?

Quando a credencial tem permissão para a ação, o agente pode, por exemplo, comentar uma entrega ou atualizar uma solicitação.

Posso consultar de outro dispositivo?

O cliente precisa alcançar o endereço do Executch. Uma instalação em localhost só é acessível localmente. Para outro dispositivo, a instalação precisa estar acessível pela rede autorizada do escritório.
